# 功能汇报与后续建议

版本：0.4.11  
日期：2026-10-29

这是一份给使用者和产品同学看的说明：不讲代码怎么实现，只讲现在页面上能做什么、哪些还不能做，以及我认为下一步值得补什么。

## 一、现在能做什么

### 1. 画布

- 画布没有固定大小，节点和组可以一直往四周摆，负坐标也能用。
- 滚轮可以放大缩小，缩放锚在鼠标位置；缩放范围已经放得很开，不再卡在原来很小的范围。
- 缩得很远时，普通视图会进入“只看组名”的状态：节点卡片、连线和端口都收起来，只留下每个组的名字，方便看全局；组名仍然可以拖动、右键操作，双击会进入这个组并恢复节点；紧凑视图和组视角不会被误收起。
- 画布里有带数字刻度和网格的平面直角坐标系，它和节点/组使用同一套世界坐标，随画布一起平移缩放，作为组的坐标参考。
- 按空格可以立刻回到整张工作流的视图中心，相当于一次“重置视图”。
- 可以拖动节点、框选多个节点、整组拖动，拖动时支持左右/上下对齐吸附。
- 页面每 5 秒自动刷新一次，也可以手动刷新。

### 2. 任务与节点

- 可以新建任务：标题必填，一行目标可以留空，建完得到一张空图。
- 可以双击空白处快速建节点，也可以用“新建节点”表单建节点。
- 节点标题、一行目标、类型改完会自动保存，不需要每次都点“保存属性”；保存按钮还留着做手动兜底。
- 节点可以设置 1–12 个进出线口，连线可以指定接在第几个口。
- 节点可以收成“仅标题”或“仅关键字”，也可以展开回完整卡片。
- 节点可以分组。分组只是画布上的圈，不影响执行。
- 新节点落在某个组框里或附近时，右键节点会出现“加入最近组”；选中节点按 `G` 也能直接加入最近的组。
- 删除节点有保护：已经起步、或者还挂着连线的节点删不掉，页面会给出原因。

### 3. 连线

- 可以画普通传递线和回边，回边只允许在已经声明的循环区里使用。
- 连线落在具体端口上；鼠标点到线附近就能选中并打开连线面板。
- 连线比较平直时直接画直线，偏得明显或两端距离较远时才变成曲线；回边仍走底部下弯的曲线。
- 连线可以设置自动门控或人工门控：
  - 自动门控：上游做完就放行；
  - 人工门控：上游做完后还要人点“确认门控”才放行。
- 已经放行过的线会被保护起来：不能改走向、不能删、不能事后加人工门控，只能放宽为自动门控或改备注。

### 4. 工作流执行规则

- 一个 agent 可以同时持有多个任务，但同时只跑一个，其余任务排队；释放一个后，排队任务会自动接上。
- 一个节点的输入可以按四种方式判定：
  - 全部满足；
  - 任意一条满足；
  - 满足指定的若干条；
  - 多条路线里只能选一条。
- 循环区有轮次上限。到达上限时不会偷偷跑下一轮，而是先要求写检查点；检查点判断没有进展，节点才会进入阻塞。
- 只有 master/lead 能调高循环上限；调高后会留痕。
- 认领、完成、返工、检查点、择一、解除阻塞目前只有接口/脚本入口，页面上主要做状态展示，没有这些操作的按钮。

### 5. 视图与布局

- 每个组可以单独整理：只重排这个组里面的节点，组的位置不动；结果记在这个组自己的相对布局里。
- 也可以全局按组整理：组按依赖关系排先后，组内继续使用各自的缓存，不把已经摆好的组内布局打乱。
- 组视角：所有组收成牌子，只画组和组之间的关系，跨组线会收成一束并标数量。
- 紧凑/堆叠视图：所有节点变成小卡，组内按各自缓存压成紧凑块，组块之间靠近摆放；组多时会自动换行。
- 紧凑视图默认允许卡片互相压住。点“允许覆盖”关闭后，会立刻做碰撞检查并整体展开，节点之间、节点和别的组框之间不再重叠；组与组始终分开。
- 可以保存多个视图图层，像图层一样切换；图层可以改名、另存为新图层，也可以覆盖当前快照。
- 当前视图有未保存改动时，切图层或切任务会提醒保存。
- `Ctrl+Z` 可以撤销视图操作（整理、切换模式、图层等），但不会撤销拖动节点、建连线这类数据修改。
- 组视角和紧凑视图是只读的，避免“看到的坐标”和库里的坐标打架。

### 6. 导入与导出

- 可以把**当前工作流 + 当前视图**导出成一个 `*.workproto.json` 文件。
- 文件里有任务信息、节点、连线、输入规则组、节点组、循环，以及当前视图的坐标、组缓存、显示模式和视口。
- 导入 JSON 会**新建一个任务**，不会覆盖现有任务；导入时会重新生成所有 ID，避免和已有数据撞主键。
- 导入完成后会自动切到新任务，并打开文件里带的视图。
- 导入导出只恢复结构和看法，不恢复执行状态：节点从“待开始”开始，租约、检查点、放行记录不会带进来。

### 7. 其他

- 模板库可以跨任务保存节点预设和组预设，之后一键套用。
- 同向链可以把“一条接一条”的节点收成一块，纯属看图方式，不改数据。
- 自带一个 150 节点的复杂示例任务，用来检查大图、组、循环、择一、门控和视图效果。

## 二、目前还不能做什么

- 「连线直接接节点组」还没有做，计划放到 0.4.12。
- 视图图层目前只存看法，不支持把节点结构也做成不同分支。
- 导入导出只带当前视图，不会把该任务的所有视图图层一起打包；也不带执行进度。
- 组视角、紧凑视图里不能直接拖节点或连线，需要先退出视图。
- 页面还没有认领、完成、检查点、择一、解除阻塞这些执行按钮，这些动作目前走接口或脚本。
- 没有任务级终审/提交按钮，原型只做到节点级。

## 三、我认为还需要加入的功能

### 优先做

1. **连线直接接组**：现在线只能接节点，组只能作为视觉容器；接组之后，组级输入输出、组级门控才完整。
2. **导出/导入时可选范围**：除了“工作流 + 当前视图”，再提供：
   - 只导结构，不带视图；
   - 导完整快照，带执行状态；
   - 导全部视图图层，不只当前一个。
3. **普通数据修改的撤销/重做**：现在 `Ctrl+Z` 只撤视图操作，拖节点、连线、改属性、建组还不能撤销；这是日常编辑最容易踩到的坑。
4. **视图图层的可见性与对比**：像图层一样能单独显示/隐藏、调整顺序、复制图层、对比两个图层；现在只能切换，不能叠加或比较。
5. **在紧凑视图里直接调整**：目前紧凑视图只读。建议允许拖动组块、调整组内顺序，松手后把结果写回对应组缓存；这样“紧凑”才真正能用来整理。
6. **大图导航**：节点搜索、定位到某个节点/组、缩略图或小地图；150 节点时只靠缩放和拖动找人还是费劲。

### 后续体验

7. **页面上的执行操作**：认领、完成、检查点、择一、解除阻塞做成按钮和表单，让不写脚本的人也能完整跑一轮工作流。
8. **导入预览与合并策略**：导入前先显示“会新建几个节点、几个组、视图名叫什么”，并允许选择“新建任务/合并到当前任务”，避免误操作。
9. **导出成图片/PDF**：把当前画布或某个视图导出为 PNG/PDF，方便评审和汇报。
10. **任务模板/版本**：把常用工作流存成模板，支持版本对比和回滚，而不只是节点/组的小预设。
11. **多人协作提示**：当前有租约和阻塞状态，建议在画布上更明确地显示谁在跑哪个节点、谁的租约快到期。
12. **移动端/触屏适配**：现在主要是桌面鼠标操作，触屏拖拽、双指缩放和右键菜单需要单独设计。
